# My Workflow

A simple loop for working on Personal CFO Tools with Claude.

## 1. Start
- Open the Claude desktop app → **Code** tab.
- Pick the **Personal-CFO-Tools** folder.

## 2. Ask
- Say what you want in plain words, e.g. "Build a monthly budget tracker."
- One goal per session keeps things clean.

## 3. Review
- Look at the changes Claude made (the diff pane).
- Ask for fixes until it's right.

## 4. Save
- Say: **"Commit and push this."**
- That saves your work to GitHub (github.com/dean4771/personal-cfo-tools).

## 5. Repeat
- Start a new session for the next idea.

---

**Three phrases to remember:**
1. "Here's what I want…"
2. "Show me what changed."
3. "Commit and push."
